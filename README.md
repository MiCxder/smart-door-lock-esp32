# Smart Door Lock (ESP32)

## Features
- RFID authentication (MFRC522)
- Keypad PIN access
- OLED display feedback
- Servo door lock control
- Buzzer alerts
- Admin mode:
  - Add card
  - Delete card
  - Change PIN
- Persistent storage (ESP32 Preferences)

## Hardware
- ESP32
- MFRC522 RFID Reader
- 4x4 Keypad
- OLED Display (SSD1306)
- Servo Motor
- Buzzer

## Admin Access
- Admin PIN: 9999

## Default User PIN
- 1520
